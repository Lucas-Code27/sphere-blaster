# Sphere Blaster

## What is this?
This repository is the source code of a game made in 2 hours. This will likely be the start of trying to make a simple game every day for about a month or so.

## Time Breakdown

> [!NOTE]
> When making this I would pause the timer whenever I was taking a break between making features. If I did include break times then the time it took to create the game would have been about 2 and a half hours.

These are rough estimates since I didn't time each feature's dev time

- 30-40 minutes | Player Movement (Did a lot of fiddling around to get the smoothed movement)
- ~20 minutes | Terrain Generation (Surprisingly simple just had to see how to directly edit a plane mesh in gdscript)
- The last hour was spent making the enemies, shooting mechanics, UI, enemy spawning, and the player model
